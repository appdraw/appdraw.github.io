# AppDraw website

Static GitHub Pages site for https://appdraw.app. No build step is required.

## Instagram download link

Use `https://appdraw.app/instagram/` in the Instagram profile. The page redirects Android visitors through the existing AppMetrica tracker and iPhone/iPad visitors to the App Store. Desktop visitors see both store buttons. The buttons remain available without JavaScript or when an in-app browser blocks automatic navigation. Common link-preview crawlers do not trigger a redirect.

Update the two `href` attributes on `#download-android` and `#download-ios` in `instagram/index.html` to change destinations; the redirect script reads the same links. Preserve the full tracking URL and encode ampersands as `&amp;` in HTML. Do not use `target="_blank"` or `rel="noreferrer"` on the tracking link.

Android currently uses the owner-provided AppMetrica app-to-app link for `instagram_bio_android` (tracking ID `894799233851348704`). iOS currently uses the ordinary App Store URL: replace it with the `instagram_bio` campaign link generated by App Store Connect to measure that campaign in Apple's analytics. The branded redirect alone does not attribute iOS installs in Firebase or AppMetrica.

Verify the published URL from Instagram on real Android and iOS devices. For installation attribution, install from the store and launch the release app; a click alone is not an install. Use an AppMetrica test device when checking reinstalls. Confirm that iPadOS desktop mode reaches the App Store and that desktop browsers keep both buttons.

GitHub Pages serves this as a static page; navigation is a client-side redirect, not an HTTP 302. No hosting migration, DNS change or app release is needed for this page.

## Terms page

`terms/index.html` contains AppDraw-specific Terms of Use, including optional Pro plans, recurring billing, cancellation, refunds, restoration, artwork rights and third-party content. The page is linked from Home, Support and Privacy. It supplements Apple's Standard EULA rather than replacing it with a custom Apple license.

The text is a draft for owner and legal review before publication. Confirm the developer details and that the purchase implementation and actual offers match it, especially restoration and the non-expiring Lifetime Pro entitlement. No prices, trial durations or cross-store purchase sharing are promised.

Publish the website changes before shipping the Android app change that links to `https://appdraw.app/terms/`. Confirm that URL returns the new page rather than a 404. The iOS app retains the direct Standard EULA link; leave the standard license enabled in App Store Connect and include its link in subscription metadata where required.
